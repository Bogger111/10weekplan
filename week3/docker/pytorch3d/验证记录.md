## 日常使用与复现

打开 Docker Desktop，在 WSL Ubuntu-24.04 中执行：

~~~bash
cd /home/bogger/10weekplan/week3
./docker/pytorch3d/p3d.sh verify
./docker/pytorch3d/p3d.sh python -m experiments.d6_check
./docker/pytorch3d/p3d.sh python -m experiments.smpl_check
~~~

CPU 备用：./docker/pytorch3d/p3d.sh verify-cpu

交互运行：./docker/pytorch3d/p3d.sh shell

重建：在 docker/pytorch3d 目录执行 ./p3d.sh build

Dockerfile、Compose、20 个依赖 wheel、requirements.lock、installed.lock.txt、image.lock.json、固定源码归档和验证脚本保存在 docker/pytorch3d。复现压缩包仅包含新增环境材料，不包含 SMPL 或原始科研数据；解压到 week3 根目录后形成 docker/pytorch3d。新机器还需取得固定基础镜像。GPU 扩展针对 sm_120，其他显卡需要重新选择编译目标。
